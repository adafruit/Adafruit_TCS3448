Detailed Description

Class for the TCS3448 14-channel multi-spectral sensor.

The inherited Adafruit_AS7343 configuration methods apply because the two devices share the relevant register addresses and bit layouts. TCS3448-named type and value aliases are provided above for sketches that should not need AS7343-prefixed constants.

◆ readData()

bool Adafruit_TCS3448::readData ( tcs3448_data_t *  data)

Read one coherent 18-result frame without waiting.

Call getDataReady() first. This method addresses ASTATUS once and reads all 36 following result bytes consecutively, so the gain, saturation flag, and ADC counts describe the same measurement. On Wire implementations with a buffer smaller than 37 bytes, Adafruit BusIO continues the read in chunks with repeated starts and no intervening stop. The sensor must be in TCS3448_SMUX_18CH mode.
